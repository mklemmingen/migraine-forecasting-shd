How to read this table

Rows (Y-axis) — Data Package
Each row is one (target × split-ratio × split-strategy) combination. target = headache or migraine. ratio = train/val/test split sizes (e.g. 70_15_15 or 70_30 / 80_20 with chronological cal sub-split). split = how rows are assigned: chrono (date-percentile cuts), stratified (class-balanced random shuffle), patient (whole-patient holdout).
Columns (X-axis) — Architecture
Each column is one (model × version × feature-set) combination. Top line: model name. Middle line (if present): version. Bottom yellow tag […]: feature-set abbreviation — see glossary below.
Cells
Top-5 metrics on the locked test set. Each metric has its own colour scale (see Colour legend). A cell tagged H+CV has both hold-out and 5-fold CV results (cell shows hold-out). A cell tagged CV only has CV results — used as fallback when hold-out is missing. Empty (—) means no result file for that combination.
